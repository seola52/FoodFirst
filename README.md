# 🥬 FoodFirst (식재료 구출 & 레시피 팩토리)

> **"냉장고 속 식재료를 먼저 구출하고, 보유한 재료로 맛있는 요리를 완성하세요!"**

FoodFirst는 사용자가 보유한 식재료를 가상 냉장고에 등록하고, 식재료의 보관 기한과 레시피 활용 가능성을 확인하여 식재료 낭비를 줄일 수 있도록 돕는 AI 융합 서비스입니다.

단순히 식재료를 보관하는 데 그치지 않고, 냉장고 속 재료를 활용할 수 있는 레시피를 추천하며 사용자 간 레시피 공유까지 지원합니다.

## 🌟 주요 기능

### 1. 🧊 사용자별 3구역 가상 냉장고

식재료를 냉장실, 냉동실, 실온으로 구분하여 관리할 수 있습니다.

- 식재료 이름에 따른 이모지 자동 매핑 및 카드형 시각화
- 식재료 이름, 수량, 보관 위치, 보관 기한 등록
- 등록된 식재료의 상세 정보 수정 및 삭제
- 소비기한 및 유통기한을 기준으로 D-day 계산
- 기한이 임박한 식재료를 화면 상단에 표시
- 사진 첨부 기능 지원 (자동 이미지 인식은 미구현)
- 로그인한 사용자별 독립적인 식재료 데이터 관리

### 2. 🍳 보유 식재료 기반 맞춤형 레시피 추천

냉장고에 등록된 식재료를 활용할 수 있도록 공공 레시피 데이터를 바탕으로 적합한 요리를 추천합니다.

- 냉장고 속 식재료 다중 선택
- 선택한 식재료와 레시피에 필요한 재료 비교
- 보유 재료 일치율(%) 계산
- 보유 중인 재료와 추가로 필요한 재료 구분
- 재료 일치율, 보유 재료 수, 추가 필요 재료 수, 조리 시간에 따른 정렬
- 식품의약품안전처 식품안전나라 조리식품 레시피 DB(COOKRCP01) 연동
- 사용자 창작 레시피도 추천 대상에 포함

### 3. ✨ 레시피 창작소 및 사용자 간 공유

사용자가 자신만의 레시피를 직접 등록하고 다른 사용자와 공유할 수 있습니다.

- 레시피 제목, 재료, 조리 순서, 조리 시간, 닉네임 등록
- 다른 사용자가 등록한 공개 레시피 확인
- 내가 등록한 레시피 관리
- 레시피를 실제로 활용했을 때 '이 레시피를 만들어 봤어요' 기능 이용
- 레시피 활용 기록에 따른 창작자 포인트 지급
- 사용자별 레시피 및 포인트 데이터 관리

### 4. 👤 회원가입 및 개인별 데이터 관리

Supabase를 활용하여 사용자 인증과 데이터 저장 기능을 구현했습니다.

- 이메일 기반 회원가입 및 로그인
- 이메일 인증을 통한 계정 확인
- 로그아웃 기능
- 사용자 계정에 연결된 개인별 냉장고 데이터 관리
- 사용자별 등록 레시피 및 창작 활동 관리
- 클라우드 데이터베이스를 통한 데이터 저장

각 사용자는 자신의 계정에 연결된 식재료를 관리하므로 다른 사용자의 개인 냉장고 데이터와 분리됩니다.

### 5. ⚙️ 데이터 관리 및 서비스 설정

- 클라우드 데이터베이스에 저장된 사용자 데이터 활용
- 개인별 식재료 및 레시피 관리
- 서비스 이용 현황 확인
- 사용자 데이터의 소유권을 고려한 데이터 접근 관리

## 🧠 AI 융합 및 문제 해결 방식

FoodFirst는 사용자의 냉장고 속 식재료 정보와 공공 레시피 데이터를 결합하여 식재료 활용을 돕는 추천 서비스를 구현했습니다.

### 주요 처리 과정

1. 사용자가 냉장고에 보유한 식재료를 등록합니다.
2. 등록된 식재료의 보관 기한과 정보를 관리합니다.
3. 공공 레시피 데이터와 사용자 창작 레시피를 활용합니다.
4. 레시피에 필요한 재료와 사용자가 보유한 재료를 비교합니다.
5. 재료 일치율과 추가 필요 재료 등을 계산합니다.
6. 사용자가 보유한 식재료를 활용하기 적합한 레시피를 확인합니다.

※ 현재 구현된 추천은 식재료 일치 여부와 조리 시간 등을 활용한 데이터 기반 매칭 방식입니다. 딥러닝 기반 이미지 인식이나 생성형 AI 모델을 직접 탑재한 것은 아닙니다.

## 📊 데이터 수집 및 활용

### 식품안전나라 조리식품 레시피 DB

- 데이터 제공 기관: 식품의약품안전처
- 데이터 출처: 식품안전나라 공공 레시피 API
- 활용 목적: 다양한 요리의 재료 및 조리 정보를 확보하여 레시피 추천에 활용
- API 서비스: COOKRCP01

[식품안전나라 공공 레시피 API 안내](https://www.foodsafetykorea.go.kr/api/openApiInfo.do?menu_grp=MENU_GRP31&menu_no=661&show_cnt=10&start_idx=1&svc_no=COOKRCP01)

## 🔍 기술적 구현 범위 및 향후 발전 방향

FoodFirst는 현재 구현 가능한 기술과 데이터 처리 방식을 바탕으로 핵심 기능을 개발하였으며, 향후 다음과 같은 방향으로 서비스를 고도화할 수 있습니다.

1. **식재료 이미지 인식 고도화:** 현재는 사진 첨부와 수동 입력을 지원하며, 향후 이미지 분류 모델을 적용하여 식재료 등록 과정을 자동화할 수 있습니다.
2. **레시피 추천 알고리즘 고도화:** 현재는 보유 식재료와 레시피 재료의 일치율을 중심으로 추천하며, 향후 사용자 선호도와 식재료의 활용 우선순위를 반영한 개인화 추천으로 발전시킬 수 있습니다.
3. **알림 기능 확장:** 현재는 앱 화면에서 기한 임박 정보를 확인할 수 있으며, 향후 푸시 알림을 추가하여 식재료 활용 시점을 놓치지 않도록 개선할 수 있습니다.
4. **서비스 안정성 강화:** 사용자 증가에 대비하여 데이터 접근 권한, 개인정보 보호, 포인트 부정 이용 방지 기능 등을 지속적으로 개선할 필요가 있습니다.

현재 구현된 기능과 향후 확장 가능한 기능을 구분하여 서비스의 실현 가능성과 발전 가능성을 함께 고려하였습니다.
