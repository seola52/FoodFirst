# 🥬 FoodFirst (식재료 구출 & 레시피 팩토리)

> **"가상 냉장고에서 식재료를 게임처럼 관리하고, 남은 재료로 요리를 추천받으며, 나만의 레시피를 공유해 포인트를 적립하세요!"**

---

## 🌟 주요 기능

1. **🧊 3구역 가상 냉장고 (냉장실 / 냉동실 / 실온)**
   - 70여 종의 식재료 자동 이모지 매핑 및 귀여운 게임 아이템 카드형 시각화
   - 소비기한 / 유통기한 D-day 계산 및 상단 임박 알림 배너
   - 식재료 등록, 상세 정보(이름, 수량, 보관 위치, 기한) 수정 및 삭제 완벽 지원
   - 사진 첨부 지원 (자동 이미지 인식 미구현 안내 및 수동 입력 유도)

2. **🍳 재료 맞춤형 레시피 추천 엔진**
   - 냉장고 속 재료를 클릭하여 다중 선택 (모두 선택 / 초기화 지원)
   - 보유 재료 일치율(%), 보유 중인 재료(초록 뱃지), 추가 필요 재료(회색 뱃지) 실시간 표시
   - 4가지 정렬 옵션:
     - 🎯 재료 일치율 높은 순
     - 🧺 보유 재료 많은 순
     - 🛒 추가 재료 적은 순
     - ⏱️ 조리 시간 짧은 순
   - 식품의약품안전처 **'식품안전나라 조리식품의 레시피 DB'** 실시간 연동
   - **인증키가 없거나 오프라인 환경에서도 사용자 창작 레시피로 완벽하게 작동**

3. **✨ 레시피 창작소 & 창작자 포인트 보상**
   - 사용자 창작 레시피 등록 (제목, 재료, 단계별 조리법, 소요 시간, 닉네임)
   - 저작권 및 콘텐츠 공유 권한 확인 체크 필수화
   - 다른 사용자가 레시피를 보고 **'이 레시피를 만들어 봤어요 (+5P)'** 클릭 시 창작자에게 포인트 자동 지급
   - 로컬 SQLite (`foodfirst.db`)에 영구 저장

4. **⚙️ 데이터 관리 및 안전 장치**
   - 로컬 DB 용량 및 등록 건수 현황 실시간 모니터링
   - 데이터 전체 초기화 시 '확인 체크박스' 안전장치 탑재 (오클릭 방지)

---

## 🚀 실행 방법

### 1. 사전 준비 (Python 및 패키지)
- **Python 3.10 이상**이 설치되어 있어야 합니다.
- 터미널(PowerShell 또는 명령 프롬프트)을 열고 의존성 패키지를 설치합니다:
  ```bash
  pip install -r requirements.txt
  ```
  *(또는 `pip install streamlit requests` 직접 설치)*

### 2. 앱 실행
- 프로젝트 폴더 위치에서 다음 명령어를 실행합니다:
  ```bash
  streamlit run main.py
  ```
- 실행 후 브라우저가 자동으로 열리거나 터미널에 표시되는 로컬 주소(`http://localhost:8501`)로 접속합니다.

## 🌐 식품안전나라 공개 레시피 API 안내

- 공공 레시피를 불러오려면 [식품안전나라 공공데이터 포털](https://www.foodsafetykorea.go.kr/api/openApiInfo.do?menu_grp=MENU_GRP31&menu_no=661&show_cnt=10&start_idx=1&svc_no=COOKRCP01)에서 API 사용 신청 후 인증키를 발급받으세요.
- 발급받은 키는:
  1. 앱 화면의 **[🍳 재료 맞춤 레시피] -> [🌐 식품안전나라 공개 레시피 API 설정]**에 직접 입력하거나,
  2. 시스템 환경변수 `FOOD_SAFETY_API_KEY`에 등록하여 사용할 수 있습니다.
- **인증키가 없어도 앱의 다른 모든 기능(냉장고 관리, 나만의 레시피 등록 및 추천)은 정상 작동합니다.**

## ⚠️ 한계 및 향후 고도화 안내 (학생 프로젝트 주의사항)

1. **AI 이미지 자동 인식:** 현재 버전은 사진 업로드만 지원하며 딥러닝 기반 식재료 자동 인식은 포함하지 않습니다. 수동 입력을 거쳐야 합니다.
2. **푸시 알림:** 기한 임박 알림은 앱이 켜져 있을 때 화면 상단에 배너로 표시됩니다. 백그라운드 푸시 알림은 별도 웹훅/모바일 서버가 필요합니다.
3. **식품 안전 주의:** 유통기한/소비기한 날짜만으로 식품의 신선도와 안전을 확정할 수 없습니다. 섭취 전 냄새, 색상, 보관 상태를 확인해야 합니다.
4. **포인트 및 보상:** 현재 포인트는 로컬 SQLite에서 시연용으로 작동합니다. 실제 상용 서비스에서는 어뷰징 방지, 본인 인증, 신고 및 검수 시스템이 필요합니다.
